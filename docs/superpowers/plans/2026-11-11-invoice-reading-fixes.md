# Исправления чтения счетов и артикулов

Основание: пользователь запросил исправить F1-F3 из аудита 11.11.2026.
Объём: идентификаторы MIN/MAX, единицы счёта, явный выбор товарных листов.
Закупочные формулы, денежные допуски и перемещения не меняются.

1. Добавить регрессии нулевой маски артикула и сверки по нему. Применить существующий безопасный читатель идентификаторов к артикулу; повысить версию парсера, чтобы повторная загрузка прежнего файла пересчитала артикул.
2. Добавить варианты заголовка единицы и регрессии неизвестных единиц на обеих сторонах. Не считать неизвестную единицу совместимой; пометить строку для ручной проверки и не включать её автоматически в корректировку. Известные несовместимые единицы сохранять раздельно.
3. При нескольких товарных листах требовать явный выбор одного или нескольких листов. Не складывать копии автоматически и не игнорировать остальные листы. Сохранить имена листов в диагностике и идентичностях строк; использовать текущие Select/Button/checkbox и защиту сброса правок. Проверить выбранное объединение 4+6=10, отдельный лист, повторные номера строк, отказ/смену файла и состояния UI.
4. Обновить предметные контракты и браузерную регрессию. Выполнить typecheck, весь Vitest, автономную сборку, статическую проверку UI и доступный E2E. Подготовить PR с фактическими результатами; не сливать.

Проверить особо: пустые единицы, шт./шт, чужие коды при совпадающем артикуле, научные форматы идентификаторов, дубли листов, пустые/неоднозначные листы и смену источника во время чтения.
