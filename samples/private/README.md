# Private local samples

Эта директория предназначена только для локальной smoke-проверки на реальных отчётах компании.

Пример локальных файлов:

```text
samples/private/Min-Max.xlsx
samples/private/Поставщики 27.08.26.xls
```

Содержимое директории игнорируется git. Не изменяйте `.gitignore` так, чтобы реальные отчёты могли попасть в публичный репозиторий.
